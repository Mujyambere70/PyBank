PyBank API

JSON API for a mobile app (version 1, sandbox bank).

How to start

  1. Ask for a token with your Customer ID and password (and the 6-digit code if two-factor login is on).
  2. Send the token in every call: Authorization: Bearer pbk_...
  3. Amounts are whole numbers of the smallest unit of the currency (paise, kopeks, cents); every amount also comes as text.
  4. A token works 30 days. You can sign an app out in Net Banking → Security.
  5. Limits: 120 calls a minute per token and 10 token requests per 10 minutes per network.

Example

curl -X POST {{ request.host_url }}api/v1/token \
     -H "Content-Type: application/json" \
     -d '{"customer_id": "PB10000001", "password": "Demo@1234", "device": "My phone"}'

curl {{ request.host_url }}api/v1/accounts -H "Authorization: Bearer pbk_..."
