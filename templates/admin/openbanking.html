How an app connects

  1. The app sends the customer to PyBank with its client ID, its return address, the permissions it wants and a PKCE code challenge.
  2. The customer signs in to Net Banking and agrees (or refuses).
  3. The app changes the one-time code for a token.
  4. With the token it can only read, for 90 days or until the customer withdraws the permission.
